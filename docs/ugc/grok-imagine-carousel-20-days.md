## How to use this pack with Grok Imagine

1. **One slide = one generation.** Every prompt below is fully self-contained; paste it as-is.
   Set aspect ratio to **9:16** in Grok's picker (TikTok full-screen photo). Editing mode keeps
   the input image's ratio automatically.
2. **Same person across slides:** generate Slide 1 of that day first. For every later slide
   showing the same person, **attach the Slide 1 image** and paste the slide prompt with this
   line in front: `Edit the attached photo: same person, same outfit, same lighting.` The
   identity wording is repeated verbatim inside each prompt on purpose - keep it unchanged.
3. **On-image text:** overlays are quoted inside the prompts and kept to ~6 words. Grok renders
   short text well but not reliably - **zoom in and proofread every slide**. If a word comes
   out wrong twice, regenerate the slide *without* the text sentence and type the overlay in
   TikTok's own text tool instead (this actually looks more native).
4. **Numbers live in captions, never in images.** Prices, peso amounts, and percentages are
   caption-only. Generated digits and currency signs are the most common text failure.
5. **Never AI-generate the app's screen.** Grok will invent a fake UI and break brand accuracy.
   Phones in these prompts are always angled with screen glare. Two slides are marked
   **[REAL SCREENSHOT]** - use an actual capture from the app or the site there.
6. **No real brands, logos, or celebrities** in prompts (moderation filter + trademark risk).
   Cups, wallets, phones, and packaging stay generic.
7. **Sound + posting:** photo carousels autoplay with sound - pick a calm trending lo-fi or
   acoustic OPM sound each day. Post once daily, evenings (roughly 6-9 PM PHT) perform best.
   Keep overlay text inside the middle of the frame; TikTok UI covers the extreme top/bottom.
