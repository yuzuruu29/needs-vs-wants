# Play Console listing assets

Generated 2026-08-21 from the live launcher mark (`app_icon_crop_center.jpg`) and the site OG image.

|------|--------------------|------|
| `play-icon-512.png` | App icon | 512×512, 32-bit PNG with alpha, under 1 MB |
| `feature-graphic-1024x500.png` | Feature graphic | 1024×500, 24-bit PNG, no alpha |

Phone screenshots are **not** in this folder. Play requires at least two real phone screenshots of the running app (JPEG or 24-bit PNG, 320–3840 px on each side). Capture them from a physical device after Internal Testing install: Summary donut, Log sheet, History filters, Paywall.

Do not invent UI mockups for the listing.
