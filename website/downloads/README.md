# Soft-launch downloads

Place the release APK here as:

`needs-vs-wants-1.0.0.apk`

Copy from the repo root `app-release.apk` (or `app/build/outputs/apk/release/app-release.apk`) after a release build.

APK binaries are gitignored (`*.apk`); this folder is tracked so the download path on the site stays stable.
