# Needs vs. Wants — Native iOS (build)

> Authored on a non-Mac host. **GitHub Actions is the compile target.** Local
> builds require macOS + Xcode 15+.

## Prerequisites (local)
- macOS 14+, Xcode 15+ (iOS 17 deployment target)
- XcodeGen: `brew install xcodegen`

## Generate & build
```sh
cd ios-native
xcodegen generate
open NeedsVsWants.xcodeproj          # or:
xcodebuild -project NeedsVsWants.xcodeproj \
  -scheme NeedsVsWants \
  -destination 'platform=iOS Simulator,name=iPhone 15' \
  build test
```

`Info.plist` is generated by XcodeGen from `project.yml` (`info.properties`) —
do not edit it by hand; edit `project.yml` and re-run `xcodegen generate`.

## CI
`.github/workflows/ios-native.yml` runs `xcodegen generate` + `xcodebuild build test`
on `macos-14`. Push to `feat/**` or `main` (touching `ios-native/**`) triggers it.
Download the `ios-native-build-logs` artifact for compile/test errors.
